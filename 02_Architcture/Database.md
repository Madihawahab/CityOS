# Database Design

# CityOS

Version 1.0

---

# Overview

CityOS uses Firebase Firestore as its primary database.

The database is organized into collections representing users, reports, AI processing, authorities, departments, analytics, and notifications.

Each civic report has a unique lifecycle tracked from submission to final resolution.

---

# Database Collections

Stores all platform users.

Fields

* userId
* fullName
* email
* phone
* role (Citizen | Authority | Admin)
* profilePhoto
* anonymousDefault (Boolean)

# Security Rules

Citizens

* Can create reports
* Can view only their own reports
* Can submit anonymous reports
* Can verify completed repairs

Authorities

* Can access only reports assigned to their department
* Cannot modify AI decisions
* Can upload repair evidence
* Can update repair progress

Administrators

* Full dashboard access
* Read analytics
* View audit logs
* Manage departments
