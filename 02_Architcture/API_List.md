# API Specification

# CityOS

Version 1.0

---

# Overview

CityOS exposes REST APIs that support citizen interactions, AI processing, authority workflows, analytics, notifications, and authentication.

Base URL

/api/v1

---

# Authentication APIs

## Register Citizen

POST

/auth/register

Purpose

Create a new citizen account.

Body

* fullName
* email
* password
* phone

Response

* userId
* JWT Token
* role

---

## Login

POST

/auth/login

Body

* email
* password

Response

* JWT Token
* User Profile
* Role

---

## Logout

POST

/auth/logout

---

## Current User

GET

/auth/me

Returns

Current authenticated user profile.

---

# Citizen APIs

## Submit Report

POST

/reports

Uploads

* Images
* Videos
* Audio
* Description
* GPS
* Anonymous Flag

Returns

* Report ID
* Status
* AI Processing Started

---

## Get My Reports

GET

/reports/my

Returns

List of reports submitted by the logged-in citizen.

---

## Get Report Details

GET

/reports/{reportId}

Returns

* Report information
* Timeline
* AI Results
* Authority Updates
* Repair Evidence

---

## Verify Repair

POST

/reports/{reportId}/verify

Body

* verified (true/false)
* feedback

---

## Nearby Issues

GET

/reports/nearby

Parameters

* latitude
* longitude
* radius

Returns

Nearby civic issues.

---

# API Design Principles

* RESTful
* Versioned (/api/v1)
* JSON-based
* Secure (JWT/Firebase Authentication)
* Role-based authorization
* Modular
* Scalable
* AI-first
